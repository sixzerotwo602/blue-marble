## 세션 개요

**주제:** 부루마블 오리지널 디지털 구현 (구성 요소 및 규칙)

### 세션 설정

우리는 오리지널 부루마블 보드게임을 분석하는 데 집중합니다. 목표는 다른 유사한 독점류 게임(Monopoly 등)의 영향을 배제하고, 원작의 메커니즘과 구성 요소를 충실하고 엄격하게 따르는 디지털 적응을 위한 포괄적인 명세를 작성하는 것입니다.

### 1단계: 형태학적 분석 (Morphological Analysis)

#### 1. 구성 요소: 보드판 (Board)

**출처:** `specs/001-core-game-engine/contracts/board-data.ts`

- **물리적 구조:** 40칸 정사각형 그리드 (한 변당 10칸).
- **타일 구성:**
  - **총 타일 수:** 40개
  - **모서리 (4개):** 출발 (0), 무인도 (10), 사회복지기금 접수처 (20), 우주여행 (30).
  - **증서 (29개):**
    - **도시:** 26개 (별장, 빌딩, 호텔 건설 가능).
    - **탈것:** 3개 (콩코드, 퀸엘리자베스, 컬럼비아 - 건물 건설 불가).
  - **특수 (7개):**
    - **황금열쇠:** 6개 타일 (2, 5, 12, 16, 22, 32).
    - **기부:** 1개 타일 (사회복지기금 기부처) (38).
- **타일 속성:** 이름, 인덱스, 타입, 컬러 그룹, 가격, 건물 건설 비용, 임대료 단계 (대지, 별장, 빌딩, 호텔).

**결정:** 기존 `board-data.ts` 파일을 보드 구성 요소의 기준(Canonical Reference)으로 삼습니다.

#### 2. 구성 요소: 자금 (Money)

**출처:** 사용자 입력

- **단위:** 원 (KRW)
- **형식:** 디지털 잔고 (물리적 지폐 권종 없음).
- **초기 자금:**
  - **2인 플레이:** 586만원
  - **3-4인 플레이:** 293만원
- **은행 메커니즘:** 무한 유동성 (은행은 파산하지 않음).

#### 3. 구성 요소: 황금열쇠 (Golden Keys)

**출처:** `specs/001-core-game-engine/contracts/golden-key-cards.ts`

- **총 카드 수:** 파일 상 27종의 구분 된 타입 정의.
- **카드 규칙:**
  - **이동:** 특정 인덱스로 이동, 뒤로 이동, 세계일주.
  - **경제:** 상금 수령, 벌금/요금 지불, 반액 대매출 (강제 매각), 건물 수리비.
  - **특수:** 무인도 탈출 (보관), 통행료 면제 (보관/거래), 사회복지기금 상호작용.
  - **분포:** 일부 카드는 중복 등장 (예: 반액 대매출, 우대권, 뒤로 이동).

**결정:** 기존 `golden-key-cards.ts` 파일이 견고한 기초를 제공하지만, 실제 카드 덱 수량(특정 종류가 몇 장씩 있는지)에 대한 검증은 필요할 수 있습니다.

#### 4. 구성 요소: 건물 (Buildings)

**출처:** 사용자 입력

- **종류:** 별장, 빌딩, 호텔.
- **타일 당 최대 건설:** 별장 2개, 빌딩 1개, 호텔 1개 (누적 건설 방식).
- **건설 규칙:**
  - **전제 조건:** 플레이어가 해당 땅을 소유해야 함.
  - **타이밍:** **후반전(Second Half)**에만 건설 가능 (모든 땅이 판매된 후).
  - **발동:** 후반전 진행 중 자신의 땅에 도착했을 때.

#### 5. 구성 요소: 주사위 (Dice)

**출처:** 사용자 입력

- **수량:** 6면체 주사위 2개 (1-6).
- **더블 규칙:** 두 주사위 합만큼 이동 -> 한 번 더 굴림.
- **트리플 더블:** 3회 연속 더블 시 -> 즉시 무인도로 이동 (턴 종료).

#### 6. 구성 요소: 게임 진행 단계 (Game Phases)

**출처:** 사용자 입력 (핵심 로직)

1.  **전반전 (First Half):**
    - 주사위를 굴리고 이동.
    - **액션:** 오직 땅 구매만 가능. 건물 건설 불가.
2.  **경매 (Auction):**
    - **발동:** 구매 가능한 땅이 정확히 **6개** 남았을 때.
    - **액션:** 남은 땅들을 경매를 통해 플레이어들에게 매각.
3.  **후반전 (Second Half):**
    - **발동:** 모든 땅이 소유된 직후 시작.
    - **액션:** 자신의 땅에 도착 시 건물 건설 가능.

### 2단계: 의사결정 트리 매핑 (Decision Tree Mapping)

#### 1. 핵심 루프 우선순위 (턴 흐름)

- **시나리오:** 플레이어가 더블을 굴림 -> 황금열쇠 도착 -> 효과: "무인도로 이동".
- **규칙:** **카드 효과가 더블 보너스보다 우선함.**
- **결과:** 플레이어 무인도로 이동 -> 턴 즉시 종료. (더블 재굴림 기회 소멸).

#### 2. 경매 및 단계 전환 ("6개 땅" 규칙)

**출처:** 사용자 입력

- **트리거:** **턴 종료** 시점에 `남은 땅 개수 == 6`인지 확인.
- **프로세스:**
  1. **게임 루프 일시 정지.**
  2. **정렬:** 남은 6개 땅을 가격순(오름차순)으로 정렬.
  3. **경매 루프:**
     - 정렬된 목록의 각 땅에 대해:
     - **시작가:** 해당 땅의 원가.
     - **입찰:** 플레이어들 입찰 진행. 최고 입찰자가 지불하고 소유.
     - **유찰:** 아무도 입찰하지 않으면 주인 없는 상태로 남음.
- **상태 변경:** 경매 루프가 끝나면 즉시 **후반전**으로 진입.

#### 3. 후반전 규칙 (경매 이후)

- **주인 없는 땅:** 플레이어가 도착하면 즉시 구매 + 건설 가능.
- **소유된 땅:** 플레이어가 자신의 땅에 도착하면 건설 가능.

#### 4. 파산 및 엣지 케이스

**출처:** 사용자 입력

- **파산 트리거:** 빚(통행료/벌금)을 갚을 현금이 부족함.
- **해결 프로세스:**
  1.  **청산 (Liquidation):** 오직 은행에만 자산 매각 가능.
      - 건물: 100% 환급.
      - 땅: 50% 환급.
  2.  **지불:** 청산된 현금으로 빚 상환.
  3.  **지급 불능 (Insolvency):** 그래도 현금이 부족하면 -> **파산 (Bankrupt)**.
      - 플레이어 게임에서 제외.
      - 남은 현금/자산은 게임에서 제거됨.

#### 5. 무인도 (고유 메커니즘)

**출처:** 사용자 입력 (공식 규칙 변형)

- **진입:** 무인도로 이동 (황금열쇠, 주사위 트리플 더블, 직접 도착).
- **기간:** 최대 3턴.
- **상태:** **영업 중** (통행료/임대료 수령 가능).
- **턴 액션:**
  - **옵션 A (탈출 시도):** 주사위 굴리기.
    - 더블: **탈출** (나온 수만큼 즉시 이동).
    - 실패: 잔류 (턴 종료).
  - **옵션 B (대기):** 굴리지 않고 스킵 (턴 종료).
- **퇴장:**
  - 더블이 나오거나.
  - 3턴이 지나면 (다음 턴에 무조건 이동).

#### 6. 우주여행 (특수 타일)

**출처:** `board-data.ts` & 사용자 입력

- **타일:** 인덱스 30 (우주여행).
- **효과:** 요금 지불 -> **원하는 칸으로 즉시 이동**.
- **요금:** 200,000원 (`TRAVEL_FEE`).
- **타이밍:** 플레이어가 해당 칸에 도착한 턴에 즉시 발동.
- **다음 턴:** 이동한 새로운 위치에서 시작.
